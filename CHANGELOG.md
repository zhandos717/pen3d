# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Агентный режим: `POST /agent` с tool-calling (`add_shape`, `update_shape`, `delete_shape`, `get_scene`, `check`, `finish`) — модель собирает деталь пошагово и сама себя проверяет.
- Серверная валидация детали в `check_scene`: связность, висящие в воздухе тела, отверстия крупнее детали, слишком тонкие стенки.
- Второй стол для агента (`plate` у объекта, `PLATE_GAP`): агент работает рядом, не трогая стол пользователя. Кнопки «Забрать к себе» и «Очистить стол агента».
- Группы объектов: перенесённая с соседнего стола деталь двигается как целое (гизмо и поля X/Y/низ), метка ⛓ в списке, кнопка «Разгруппировать».
- Выбор стола для печати: STL, отправка на принтер, габарит и превью «Результат» берут выбранную доску. Активный стол подсвечен, камера перелетает к нему с анимацией.
- Счётчик расхода токенов за сессию с кнопкой сброса.
- История ответов ИИ в интерфейсе (`GET /ai-log`), клик по записи подставляет запрос обратно.
- Примитивы: шар, конус, кольцо, клин и настоящая метрическая резьба; наклон по всем трём осям.
- Настройки слайсера из редактора: поддержки, плотность и паттерн заполнения, число периметров.
- `icon.svg` — иконка проекта, подключена как favicon в обоих редакторах.
- `CHANGELOG.md`.

### Changed
- Состояние переехало из `localStorage` и `ai-log.jsonl` в SQLite (`db.py`, база `pen3d.db`): сцена, библиотека эскизов, лог ИИ, счётчик токенов. Старые данные переносятся автоматически при первом запуске. API-ключи остаются в браузере.
- Статика переехала в `web/`; сервер раздаёт только её.
- Скрипт редактора разбит на ES-модули `web/js/{app,geometry,csg,stl,ai}.js` — без сборки, через `importmap`.

### Fixed
- `do_POST` падал на запросе без тела (удаление эскиза) — `content-length` теперь необязателен.
- `bridge.py` отдавал `.svg` как `application/octet-stream` — браузер не показывал favicon.

### Security
- Раньше `GET /bridge.py` и `GET /ai-log.jsonl` отдавали эти файлы любому, кто знал путь. Теперь корень раздачи — `web/`.

## [0.1.0] — 2026-09-02

Первый публичный релиз.

### Added
- 3D-редактор в браузере (`index.html`): примитивы, булевы отверстия, гизмо перемещения / вращения / масштаба, привязка 1 мм / 15°, история undo/redo, автосохранение сцены в `localStorage`.
- AI-помощник по модели: DeepSeek и любой OpenAI-совместимый endpoint через `POST /ai`, Anthropic — напрямую из браузера. Лог ответов в `ai-log.jsonl`, просмотр через `GET /ai-log`.
- `bridge.py`: раздача статики, слайсинг STL через Bambu Studio CLI, заливка `.3mf` на принтер по FTPS (implicit TLS, 990), старт печати по MQTT (8883).
- Настройки слайсинга из редактора: поддержки, плотность и паттерн заполнения, число периметров.
- `--selfcheck` — прогон куба через слайсер с проверкой gcode внутри `.3mf`.
- `--lan` — слушать все интерфейсы вместо localhost.
- Старый 2D-редактор сохранён как `editor-2d-old.html`.

## Дальше

Порядок — по тому, что мешает прямо сейчас.

### Ближайшее
- **Скриншот редактора в README.** Сейчас проект продаётся одним абзацем текста.
- **Прогресс печати.** MQTT-топик `device/<serial>/report` уже отдаёт слой, температуру и ETA — подписаться и показать в редакторе; сейчас после старта печати обратной связи нет вообще.
- **Ошибки слайсера человеческим языком.** `RuntimeError` с 1600 символами вывода CLI летит в UI как есть.
- **Anthropic-ключ уходит из браузера напрямую** (`anthropic-dangerous-direct-browser-access`) и лежит в `localStorage`. Проксировать через `/ai`, как остальных провайдеров.

### Потом
- **Импорт STL** — открыть чужую модель, а не только рисовать свою.
- **Выбор филамента и профиля процесса из UI.** Сейчас `PRESETS` зашиты в `bridge.py`, смена профиля = правка кода.
- **Токен для `--lan`.** Флаг открывает печать на всю локальную сеть без авторизации.
- **Скругления и фаски** — самое частое, чего не хватает после примитивов.
- **Экспорт/импорт проекта в файл.** `localStorage` умирает вместе с профилем браузера.

### Может быть
- Linux и Windows: пути к Bambu Studio и профилям зашиты под macOS.
- Другие принтеры Bambu (P1/X1) — протокол тот же, отличаются пресеты.
- Превью gcode послойно перед печатью.
