## [0.1.0] — 2026-09-02

Первый публичный релиз.

### Added
- 3D-редактор в браузере (`index.html`): примитивы, булевы отверстия, гизмо перемещения / вращения / масштаба, привязка 1 мм / 15°, история undo/redo, автосохранение сцены в `localStorage`.
- AI-помощник по модели: DeepSeek и любой OpenAI-совместимый endpoint через `POST /ai`, Anthropic — напрямую из браузера. Лог ответов в `ai-log.jsonl`, просмотр через `GET /ai-log`.
- `bridge.py`: раздача статики, слайсинг STL через Bambu Studio CLI, заливка `.3mf` на принтер по FTPS (implicit TLS, 990), старт печати по MQTT (8883).
- Настройки слайсинга из редактора: поддержки, плотность и паттерн заполнения, число периметров.
- `--selfcheck` — прогон куба через слайсер с проверкой gcode внутри `.3mf`.
- `--lan` — слушать все интерфейсы вместо localhost.
- Старый 2D-редактор сохранён как `editor-2d-old.html`.

## Дальше

Порядок — по тому, что мешает прямо сейчас.

### Ближайшее
- **Скриншот редактора в README.** Сейчас проект продаётся одним абзацем текста.
- **Прогресс печати.** MQTT-топик `device/<serial>/report` уже отдаёт слой, температуру и ETA — подписаться и показать в редакторе; сейчас после старта печати обратной связи нет вообще.
- **Ошибки слайсера человеческим языком.** `RuntimeError` с 1600 символами вывода CLI летит в UI как есть.
- **Anthropic-ключ уходит из браузера напрямую** (`anthropic-dangerous-direct-browser-access`) и лежит в `localStorage`. Проксировать через `/ai`, как остальных провайдеров.

### Потом
- **Импорт STL** — открыть чужую модель, а не только рисовать свою.
- **Выбор филамента и профиля процесса из UI.** Сейчас `PRESETS` зашиты в `bridge.py`, смена профиля = правка кода.
- **Токен для `--lan`.** Флаг открывает печать на всю локальную сеть без авторизации.
- **Скругления и фаски** — самое частое, чего не хватает после примитивов.
- **Экспорт/импорт проекта в файл.** `localStorage` умирает вместе с профилем браузера.

### Может быть
- Linux и Windows: пути к Bambu Studio и профилям зашиты под macOS.
- Другие принтеры Bambu (P1/X1) — протокол тот же, отличаются пресеты.
- Превью gcode послойно перед печатью.
